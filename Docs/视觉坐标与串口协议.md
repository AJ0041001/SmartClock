# SmartClock 游戏视觉对接说明

## 1. 游戏区域与坐标

- 屏幕逻辑尺寸：`480 × 800 px`
- 游戏白色外框：`430 × 590 px`
- 外框左上角：水平居中，垂直坐标约为 `y = 78`
- 外框边框：`3 px`
- 游戏内部有效区域：`424 × 584 px`
- 游戏内部坐标原点：白色游戏区域左上角内侧，记为 `(0, 0)`
- 坐标方向：向右为 `+X`，向下为 `+Y`

红色挡板尺寸为 `70 × 13 px`。程序内部保存的是挡板左上角坐标：

```text
挡板 X 范围：0 .. 354
挡板 Y 范围：0 .. 571
```

视觉端发送的是挡板中心坐标，程序会自动转换并限幅：

```text
中心 X 有效范围：35 .. 389
中心 Y 有效范围：6 .. 578
挡板左上角 X = clamp(中心 X, 35, 389) - 35
挡板左上角 Y = clamp(中心 Y, 6, 578) - 6
```

因此视觉端即使发送越界坐标，单片机也会把挡板放在最近的边界，不会出界。

## 2. USART2 数据帧

串口：`USART2`，使用接收空闲中断接收。帧固定为 10 字节，小端序：

```text
字节 0   0xAA       帧头 1
字节 1   0x55       帧头 2
字节 2   0x06       有效载荷长度，固定为 6
字节 3   TYPE       控制类型：01 或 02
字节 4   X_L        X 坐标低字节
字节 5   X_H        X 坐标高字节
字节 6   Y_L        Y 坐标低字节
字节 7   Y_H        Y 坐标高字节
字节 8   RESERVED   保留字段，当前填 0x00
字节 9   CRC8       CRC-8 校验
```

CRC 计算范围为字节 `2..8`，共 7 字节。算法：初值 `0x00`，多项式 `0x07`，逐字节异或后逐位计算，最高位移出时异或 `0x07`。

### TYPE 说明

- `TYPE = 0x01`：串口坐标与按键共同控制。串口坐标作为基准，按键移动量叠加在基准坐标上。
- `TYPE = 0x02`：只使用按键控制。X/Y 字段仍需填写并校验，但不会改变挡板位置。

如果一段时间没有收到新的串口帧，程序会自动回退到按键控制，并保持挡板当前位置不跳变。

## 3. 示例帧

下面示例的坐标为中心坐标 `(212, 578)`，保留字段为 `0x00`：

```text
AA 55 06 01 D4 00 42 02 00 CRC
```

```text
AA 55 06 02 D4 00 42 02 00 CRC
```

`CRC` 必须由视觉端按上述 CRC-8 算法计算，不能直接照抄示例中的文字 `CRC`。

## 4. 单片机回传

- 有效帧：`OK\r\n`
- 无效帧：`ERROR\r\n`

回传使用 USART2 发送端，视觉端应按完整字符串接收。

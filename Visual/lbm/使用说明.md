# 鲁班猫4 卡片识别 — 文件说明与使用指南

用 YOLO26 训练一个识别卡片的检测模型，转成 RKNN 格式部署到鲁班猫4（RK3588S 芯片，Rockchip NPU）。

---

## 一、目录结构

```
Visual/lbm/
├── README.md            # 简版流程（快速上手看这个）
├── 使用说明.md           # 本文档（每个文件的详细说明）
│
├── convert_cards.py     # 脚本1：整理数据集
├── convert_rknn.py      # 脚本2：ONNX → RKNN
├── rknn_card_infer.py   # 脚本3：板子端推理
│
├── model/               # 模型文件
│   ├── best.pt          #   训练权重（PyTorch）
│   ├── best.onnx        #   中间格式（转换输入）
│   └── best.rknn        #   最终 NPU 模型 ★ 上板子用
│
└── runtime/             # 板子运行库（版本必须 2.3.2）
    ├── librknnrt.so     #   NPU 底层运行库 ★
    └── rknn_toolkit_lite2-2.3.2-cpXX-*.whl   # Python 接口 ★（6 个，选对版本）
```

带 ★ 的是**最后部署到板子上必须用到的文件**。

## 二、代码文件（3 个脚本）

### 1. convert_cards.py —— 整理数据集

- **作用**：把 Roboflow 导出的多边形（分割）标签，转成 YOLO 检测用的矩形框，并生成 `data.yaml`。
- **运行环境**：Windows 电脑（不需要 GPU）。
- **用法**：改文件开头的 `SRC`（源数据路径）和 `DST`（输出路径），然后：
  ```bash
  python convert_cards.py
  ```
- **产物**：`card_dataset/` 目录 + `data.yaml`。

### 2. convert_rknn.py —— ONNX 转 RKNN

- **作用**：把 `best.onnx` 编译成 NPU 能跑的 `best.rknn`（FP16，target_platform = rk3588）。
- **运行环境**：WSL Ubuntu，`toolkit2` conda 环境（Python 3.11 + rknn-toolkit2 2.3.2）。
- **用法**：把 `best.onnx` 放在同目录，然后：
  ```bash
  python convert_rknn.py    # 生成 best.rknn
  ```
- **产物**：`best.rknn`（最终上板模型）。

### 3. rknn_card_infer.py —— 板子端推理

- **作用**：在鲁班猫4 上加载 `best.rknn`，对图片做卡片检测，打印每个框的置信度，画框后保存 `result.jpg`。
- **运行环境**：鲁班猫4 板子（装好 runtime 后）。
- **用法**：
  ```bash
  python3 rknn_card_infer.py 图片.jpg
  ```
- **可调参数**（文件顶部）：`CONF=0.5`（置信度阈值，漏检就调低）、`NMS=0.45`（去重叠框）。

## 三、模型文件（model/）

| 文件 | 大小 | 是什么 | 什么时候用 |
|------|------|--------|-----------|
| `best.pt` | 20MB | 训练出的 PyTorch 权重，整个流程的源头 | 想**重新训练**或**重新导出**时 |
| `best.onnx` | 9.4MB | 导出中间格式，pt 和 rknn 之间的桥梁 | 运行 `convert_rknn.py` 的输入 |
| `best.rknn` | 7MB | **最终 NPU 模型**，板子上真正跑的 | **部署到板子** |

三者关系（转换链）：

```
best.pt  --(yolo export)-->  best.onnx  --(convert_rknn.py)-->  best.rknn
  训练产物                        中间格式                         上板模型
```

> 一般只关心 `best.rknn`（上板）和 `best.pt`（留着重训/重导出）。`best.onnx` 只是中间产物，需要时可从 `best.pt` 用 `yolo export model=best.pt format=onnx imgsz=640` 重新生成。

## 四、运行库（runtime/）

这两个是板子上**缺一不可**的东西，且**版本必须和模型匹配（都是 2.3.2）**。模型是用 2.3.2 编译的，运行库换版本会报错。

### 1. librknnrt.so（7.4MB）

- **作用**：RKNN 的 NPU 底层运行库，板子上 CPU 靠它调度 NPU。
- **部署**：拷到板子后：
  ```bash
  sudo cp librknnrt.so /usr/lib/
  sudo ldconfig
  ```

### 2. rknn_toolkit_lite2-2.3.2-cpXX-*.whl（6 个，各 ~500KB）

- **作用**：板子上用 Python 调用 NPU 的封装包（`from rknnlite.api import RKNNLite` 就是靠它）。
- **选哪个**：文件名里的 `cpXX` 对应 Python 版本——
  | 文件名标记 | Python 版本 |
  |-----------|-------------|
  | cp37 / cp38 / cp39 | 3.7 / 3.8 / 3.9 |
  | cp310 / cp311 / cp312 | 3.10 / 3.11 / 3.12 |
- **部署**：先看板子 Python 版本 `python3 --version`，再装对应的那个：
  ```bash
  pip3 install rknn_toolkit_lite2-2.3.2-cp311-cp311-manylinux_2_17_aarch64.manylinux2014_aarch64.whl
  ```
  （上例是 Python 3.11 的情况，请按实际版本换文件名）

## 五、完整部署步骤（板子侧）

假设板子能联网、用 `lubancat` 账号登录（IP 用 `ifconfig` 查）。

**① 传文件到板子**（在 Windows 的 WSL 终端里，scp 走网络）

```bash
scp model/best.rknn                lubancat@<板子IP>:~/
scp rknn_card_infer.py             lubancat@<板子IP>:~/
scp runtime/librknnrt.so           lubancat@<板子IP>:~/
scp runtime/rknn_toolkit_lite2-2.3.2-cp311-*.whl  lubancat@<板子IP>:~/
```

**② 板子上装运行库**（SSH 进板子后）

```bash
sudo cp librknnrt.so /usr/lib/ && sudo ldconfig
pip3 install rknn_toolkit_lite2-2.3.2-cp311-*.whl   # 按 Python 版本选
```

**③ 跑检测**

```bash
python3 rknn_card_infer.py 你的卡片图片.jpg
# 输出每个框的置信度，并保存 result.jpg
```

## 六、重新训练 / 换数据集的完整流程

1. `convert_cards.py` → 生成数据集（Windows）
2. `yolo detect train model=yolo26n.pt data=data.yaml epochs=150 imgsz=640` → 得到 `best.pt`（Windows，yolo8 环境）
3. `yolo export model=best.pt format=onnx imgsz=640` → 得到 `best.onnx`
4. `convert_rknn.py` → 得到 `best.rknn`（WSL）
5. 用 `rknn_card_infer.py` 在板子上推理
